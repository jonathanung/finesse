# Cancel Finesse

The user wants to cancel the current Finesse planning session.

1. If you are currently in plan mode, acknowledge the cancellation and stop planning.
2. Do NOT write any plan files to `finesse-plans/`.
3. Do NOT output any ralph-loop commands.
4. Say: "Finesse planning cancelled. No plan was saved."
